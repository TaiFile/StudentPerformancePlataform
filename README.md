## 📖 Sobre o Projeto

O **Student Performance Platform** é uma plataforma que une conceitos de **Data Science** e **Engenharia de Software** para oferecer uma experiência completa de acompanhamento do desempenho acadêmico de estudantes.

Através de análises de dados e visualizações intuitivas, professores e alunos podem identificar padrões, pontos de melhoria e acompanhar a evolução ao longo do tempo.

---

## ✨ Funcionalidades

- 📊 **Dashboard de Desempenho** — Visualize métricas e indicadores de desempenho de forma clara
- 📈 **Análise de Dados** — Relatórios gerados com técnicas de Data Science
- 👩‍🎓 **Gestão de Estudantes** — Cadastro e acompanhamento individualizado de alunos
- 🔔 **Alertas e Notificações** — Identifique automaticamente alunos que precisam de atenção
- 📅 **Histórico Acadêmico** — Acompanhe a evolução ao longo do tempo

## 🚀 Como Começar

### Pré-requisitos

- [Node.js](https://nodejs.org) (versão recomendada: LTS)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/TaiFile/StudentPerformancePlataform.git

# 2. Acesse a pasta do projeto
cd StudentPerformancePlataform

# 3. Instale as dependências
npm install

# 4. Inicie a aplicação
npm start
```
