# Data Science Notebooks

This directory contains Jupyter notebooks for exploratory data analysis and model development.

## Contents

- **EDA**: Exploratory data analysis of student performance data
- **Clustering**: K-Means clustering analysis for student segmentation
- **Classification**: Random Forest model for academic failure risk prediction
- **Correlation**: Pearson correlation analysis between behavioral/socioeconomic variables and scores

## Running Notebooks

```bash
pip install jupyter pandas scikit-learn matplotlib seaborn
jupyter notebook
```
